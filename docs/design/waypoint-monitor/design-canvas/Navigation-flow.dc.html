Rules
· Hash routing (#/…) needs no server rewrites; the page title follows the route (“CallRail · History · Waypoint Monitor”).
· Opening a run drawer does not change the address; closing it returns focus to its row.
· Moving between routes closes the drawer, scrolls to the top and keeps the List | Graph choice.
